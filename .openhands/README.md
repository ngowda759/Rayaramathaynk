# OpenHands Templates

This directory contains templates and guides for OpenHands AI agents working on this project.

## Files

| File | Purpose |
|------|---------|
| `project-context.md` | Persistent project context for all sessions |
| `prompt-template.md` | Template for task prompts |
| `review-checklist.md` | Code review checklist |
| `feature-template.md` | Feature implementation template |
| `sprint-template.md` | Sprint planning template |

## Usage

### Starting a New Task

1. Read `project-context.md` for project overview
2. Use `prompt-template.md` to structure your task
3. Reference `review-checklist.md` before committing

### Implementing a Feature

1. Create feature document using `feature-template.md`
2. Implement following documentation in `/docs/`
3. Review using `review-checklist.md`
4. Document decisions in the feature doc

### Sprint Planning

1. Use `sprint-template.md` for sprint planning
2. Generate tasks using the format in the template
3. Track progress using the sprint board

## Guidelines

- Always read `project-context.md` first
- Follow the Definition of Done in all tasks
- Use the review checklist before every commit
- Document all significant decisions
- Update documentation when adding features
