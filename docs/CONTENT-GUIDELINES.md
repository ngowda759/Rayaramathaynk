## Overview

This document defines content standards for the Sri Raghavendra Swamy Matha website. It ensures consistent, high-quality content across all pages, AI responses, and user-facing text. It answers: "How should content be written?"

---

## Tone of Voice

### Core Values

| Value | Description | Example |
|-------|-------------|---------|
| **Devotional** | Reflects spiritual reverence | "The sacred waters of the Brindavan" |
| **Respectful** | Honors traditions and elders | "The pontiff's teachings" |
| **Factual** | Accurate historical information | "Established in 1678" |
| **Accessible** | Welcoming to all devotees | "Open to visitors from 5:30 AM" |
| **Warm** | Personal and heartfelt | "We welcome you with love" |

### Writing Style

#### ✅ Use

- Simple, clear language
- Active voice
- Present tense for current information
- Inclusive terms ("devotees", "visitors")
- Proper titles (Swamy, Maharshi, etc.)

#### ❌ Avoid

- Casual or slang language
- Passive voice
- Exaggerated claims
- Sectarian language
- Outdated or offensive terms

### Examples

#### Event Descriptions

```markdown
# ✅ Correct
"Join us for the auspicious celebration of Raghavendra Swamy's Brindavan Sthapana 
Utsav. Witness the divine rituals and receive the pontiff's blessings."

# ❌ Incorrect
"Come check out the party at Brindavan! It's gonna be awesome!"
```

#### Temple Timings

```markdown
# ✅ Correct
"The temple opens for Suprabhata at 5:30 AM. Morning pujas continue until 
12:00 PM. The temple reopens at 4:00 PM for evening darshan."

# ❌ Incorrect
"We open early and close around noon, then open again sometime in the evening."
```

## Language Standards

### English

#### Style Guide

- **American spelling** (honor, color, center)
- **Title case** for headings
- **Sentence case** for navigation and buttons
- **Proper capitalization** for deity names and sacred terms

#### Punctuation

- Use the Oxford comma
- Use en-dashes (–) for ranges (5:30 AM – 12:00 PM)
- Use curly quotes ("") instead of straight quotes

### Kannada

#### Script Standards

- Use Kannada script (ಕನ್ನಡ) for all Kannada text
- Unicode encoding (UTF-8)
- Proper conjunct letters (ಕ್ಷ, ತ್ರ, etc.)

## Date & Time Formatting

### Date Formats

| Context | Format | Example |
|---------|--------|---------|
| Display | "MMMM D, YYYY" | "January 15, 2026" |
| Kannada | "D MMMM YYYY" | "15 ಜನವರಿ 2026" |
| API/Storage | "YYYY-MM-DD" | "2026-01-15" |
| Relative | "X days ago" | "3 days ago" |

### Time Formats

| Context | Format | Example |
|---------|--------|---------|
| Display | "h:mm AM/PM" | "5:30 AM" |
| 24-hour | "HH:mm" | "05:30" |
| Range | "h:mm AM – h:mm PM" | "5:30 AM – 12:00 PM" |
| Kannada | Roman (for Kannada pages) | "ಬೆಳಿಗ್ಗೆ 5:30" |

### Hindu Calendar

| Element | Format | Example |
|---------|--------|---------|
| Tithi | "Shukla Paksha Ekadashi" | "Shukla Paksha Dwadashi" |
| Nakshatra | Name only | "Uttara Phalguni" |
| Festival | Full name with year | "Raghavendra Swamy Aradhana 2026" |

## Event Description Standards

### Structure

Every event description should include:

```markdown
## [Event Name]

### Quick Info
- Date: [Date]
- Time: [Time]
- Location: [Location]
- Entry: [Free/Open to all/By registration]

### About
[2-3 sentences about the event's significance]

### Highlights
- [Key highlight 1]
- [Key highlight 2]
- [Key highlight 3]

### How to Participate
[Registration details or walk-in information]
```

### Length Guidelines

| Element | Min | Max | Purpose |
|---------|-----|-----|---------|
| Event title | 5 words | 10 words | SEO, clarity |
| Short description | 20 words | 50 words | Cards, listings |
| Full description | 100 words | 300 words | Event page |
| About section | 50 words | 100 words | Background |

### Image Requirements

| Context | Dimensions | Size | Format |
|---------|------------|------|--------|

| Thumbnail | 400 x 300 | < 100 KB | WebP |
| Gallery | 1200 x 800 | < 300 KB | WebP |
| OG Image | 1200 x 630 | < 200 KB | WebP |

### Heading Structure

```html
<h1>Page Title (one per page)</h1>
  <h2>Major Sections</h2>
    <h3>Subsections</h3>
      <h4>Details</h4>
```

| Type | Density | Usage |
|------|---------|-------|
| Primary | 1-2% | Title, H1, first paragraph |
| Secondary | 0.5-1% | Headings, body |
| Long-tail | Natural | Questions, conversational |

## AI Content Generation

### Raya AI Response Standards

When generating AI responses, follow these guidelines:

#### Structure

```
[Greeting in user's language]
[Direct answer to question]
[Additional context if helpful]
[Source citation]
[Offer to help]
```

#### Example: Temple Timings

```
# User asks: "What time does the temple open?"

# English response:
"Namaste! The temple opens for Suprabhata at 5:30 AM every morning. 
Morning darshan continues until 12:00 PM. The temple reopens at 
4:00 PM for evening darshan, which concludes at 9:00 PM.

📖 Source: Temple Timings

Is there anything else you'd like to know about visiting the temple?"
```

#### Language Detection

| User's Language | Response Language |
|-----------------|-------------------|
| English | English |
| Kannada (ಕನ್ನಡ) | Kannada (ಕನ್ನಡ) |
| Mixed | Match dominant language |

### Content Prohibition

The AI should **never** generate:

1. **Fabricated facts** — Only use verified temple data
2. **Astrological predictions** — Redirect to qualified sources
3. **Medical claims** — Temple water/prasad healing claims
4. **Sectarian content** — Comparisons with other religions
5. **Commercial promotion** — Third-party products/services
